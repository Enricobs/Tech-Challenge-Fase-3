# Tech Challenge — Fase 3
## Big Data & Analytics — State of Data Brazil
Projeto desenvolvido para análise do mercado brasileiro de Dados,
utilizando as pesquisas State of Data Brazil de 2023–2024,
2024–2025 e 2025–2026.

## Objetivo
Analisar o perfil dos profissionais de Dados no Brasil,
identificando padrões relacionados a cargos, senioridade,
remuneração, gênero, tecnologias, Inteligência Artificial,
região e modelos de trabalho.

## Tecnologias
- Amazon S3
- AWS Glue
- AWS Glue Data Catalog
- Amazon Athena
- Spark / PySpark
- SQL
- Python
- Matplotlib
- Draw.io

## Estrutura
architecture/ → arquitetura AWS
notebooks/ → notebooks utilizados
scripts/ → scripts Glue e Spark/PySpark
sql/ → consultas SQL
results/graficos/ → visualizações utilizadas nas análises
